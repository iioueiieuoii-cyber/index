余白日誌 - X観測ログ prototype v0.1
=================================

【何ができるか】
・Xの投稿URL、本文、メモ、スクリーンショットをiPhoneのブラウザ内に保存
・日付ごとの閲覧、検索、カレンダー表示、投稿の編集・削除
・1日の投稿から日誌の「下書き」を生成し、加筆して保存
・JSON形式でバックアップ / 復元
・Xの共有メニューを受けるためのURLパラメータ ?url= と ?text= に対応

【重要な制約】
・URLから投稿本文を自動で取りに行く機能はありません（X API未接続）。
  URLとともに投稿本文をコピーして貼り付けるか、スクリーンショットを添付してください。
・「日誌の下書き」は投稿文を列挙するもので、AIによる要約ではありません。
・クラウドサーバー・ログイン・AI API・外部送信は使いません。
・保存先はIndexedDB（HTTPSで公開したWebページを開いたiPhoneのSafari内）。
・URLを開くのにサイトのHTTPS公開が必要です。このHTML単体を「ファイル」から開く方法は、iPhoneでの永続保存が保証されません。
・サイトデータ消去・ブラウザの変更・端末故障でデータが消える可能性があります。定期的にJSONバックアップしてください。
・このアプリは非公開・個人利用の想定です。Xの投稿保存では著作権や利用条件にご注意ください。

【iPhoneで使う方法（推奨）】
1) index.htmlを静的ホスティングのHTTPSサイトで公開します。
   例：Netlify Drop、GitHub Pages等。
   アプリのプログラムをサイトに置くだけで、投稿記録はサーバーに送信されません。
   ただしURLやテキストをショートカットのURLクエリに含める場合、
   ホスティング事業者のアクセスログ等に記録される可能性がある点にご注意ください。
2) iPhoneのSafariで公開したURLを開きます。
3) Safariの共有ボタンから「ホーム画面に追加」を選びます。
4) 「記録」画面にXの投稿URL、本文、任意のスクリーンショットを入力して保存します。
5) 「日誌」画面の日付を選び、下書きを生成→必要に応じて編集→保存します。
6) 「設定」画面からバックアップを定期的に書き出します。

【共有ショートカット連携（発展）】
「ショートカット」アプリで「共有シートで表示」を有効にし、URLを受け取る設定をします。
受け取ったURLをURLエンコードして、公開したアプリのURLの末尾に
?url=<エンコードされたX投稿URL>
を付けて「URLを開く」アクションで開いてください。
例えば、公開URLが https://example.com/index.html の場合：
https://example.com/index.html?url=https%3A%2F%2Fx.com%2Fsomeone%2Fstatus%2F1234567890
共有されたテキスト本文を渡すなら &text=<エンコード済みテキスト> も使えます。
※Xアプリからの共有で、全文テキストが必ず提供されるわけではありません。
※クエリに入れた内容はアプリ起動後、ブラウザのアドレスバーから削除されますが、
  アクセスログ等への記録を防げる保証はありません。機密情報を渡さないでください。

【データ移行】
JSONバックアップの形式は、posts[] と journals[] を持つものです。
将来サーバー保存に切り替える際のインポート元として使えるようにしています。
